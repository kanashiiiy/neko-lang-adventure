# NekoTeach: Your Language Companion

Crie um aplicativo profissional para Android e iOS chamado NEKOTeach.

OBJETIVO

O NEKOTeach é um aplicativo de aprendizado de idiomas inspirado na simplicidade e gamificação do Duolingo, porém com identidade própria. O aplicativo deve ser completo, moderno, rápido e responsivo.

IDENTIDADE VISUAL

Nome: NEKOTeach

Mascote: Um gato preto de desenho animado chamado Neko.

O Neko é simpático, divertido, expressivo e aparece apenas para explicar funcionalidades, dar boas-vindas, incentivar o usuário e comemorar conquistas.
